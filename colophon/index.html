Colophon

How this site is made, from the tools behind it to the details on the page.

Stack

Built with Astro as a fully static site — every page is rendered at build time, no client framework. Content is plain markdown; the build runs on GitHub Actions and deploys to GitHub Pages. Comments run on Giscus, backed by GitHub Discussions.

Type

One face does the whole site: Inter, self-hosted as a variable font, at weights no heavier than 600 — headings included. Tracking tightens slightly on titles and sits at zero for body text. A mono face is kept for one job only: metadata, set at 11px in brackets. Nothing is fetched from a CDN and nothing shifts while loading.

Colour

Almost none. The page is paper and ink: one ground, one four-step ink ramp, one hairline value. A single accent exists and is spent sparingly — links, hover, the field you are typing in — never to colour-code a kind of content. There are four token sets (light and dark, in each of two spaces), and the geometry is identical across all of them, so switching space or theme repaints the page without moving anything on it.

Drawing language

Whitespace divides and hairlines punctuate. Three radii and no more: pills for links and tags, 12px for card surfaces, and nothing at all on list rows. Icons are a bespoke set drawn on a 24px grid with a sharp 1.5px stroke. Motion is paint-only — colour and shadow, 150 to 320ms — and switches off entirely when the reader asks for reduced motion.

The graph

Posts link to each other with wiki-style links; backlinks and theglobal graph are derived from them at build time, force-layout included — the reader downloads coordinates, not a physics engine.
